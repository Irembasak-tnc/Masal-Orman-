# Masal Ormanı

Masal Ormanı, Türk masallarını fantastik ve büyülü bir orman atmosferinde sunan etkileşimli bir web sitesidir.

## Proje Hakkında
Bu projede sekiz farklı Türk masalı bir araya getirilmiştir. Ziyaretçiler masal kartlarına tıklayarak masalların içeriklerini okuyabilir.

## Nasıl Açılır?
Bilgisayarınıza `index.html` dosyasını indirin ve bir web tarayıcısında açın.

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript
